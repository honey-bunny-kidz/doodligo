# Doodligo media

PLAY • LEARN • DISCOVER — preschool learning videos with Dodo and Dini.

- `videos/` – rendered episodes (published to YouTube via Sonap)
- `thumbnails/` – YouTube thumbnails
- `episodes/` – episode scripts
- `engine/` – renderer (`python3 engine/render.py episodes/ep01_colors.py videos/dl001_colors.mp4`)
